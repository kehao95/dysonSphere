# Visualization Demos

## MDDS Deployment Simulator

Open [mdds_deployment_sim.html](/Users/kehao95/Projects/personal/dysonSphere/docs/visualization/mdds_deployment_sim.html) in a browser to explore a stylized 3D view of:

- the Sun
- Earth on a 1 AU reference orbit
- progressively deployed MDDS node bands

The demo is intentionally schematic:

- orbital and body sizes are not to scale
- vertical displacement can be exaggerated for readability
- the displayed formulas follow the ideal-sail high-level theory used in this repository

Use the controls to switch between:

1. near-ecliptic seed deployment
2. low-latitude operational belt
3. layered latitude expansion
4. a fuller concept view
