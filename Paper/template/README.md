# MNRAS Template and Build Wrapper

This directory is the single active paper build surface.

- Canonical manuscript content lives in [`/Users/kehao95/Projects/personal/dysonSphere/Paper/content/manuscript.md`](/Users/kehao95/Projects/personal/dysonSphere/Paper/content/manuscript.md)
- Canonical bibliography lives in [`/Users/kehao95/Projects/personal/dysonSphere/Paper/references/bibliography.bib`](/Users/kehao95/Projects/personal/dysonSphere/Paper/references/bibliography.bib)
- `mnras.latex` is the Pandoc LaTeX template
- `support/mnras` contains the MNRAS class assets used by the build
- Build artifacts are emitted to the sibling [`/Users/kehao95/Projects/personal/dysonSphere/Paper/output`](/Users/kehao95/Projects/personal/dysonSphere/Paper/output) directory
